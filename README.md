## 📝 Abstract

The Linux Kernel Monitoring System is a C-based system monitoring application designed to observe the current state and activity of a Linux operating system. The system collects information from the `/proc` filesystem to monitor running processes, process IDs, parent process IDs, process states, CPU usage, memory usage, and other system resources. It continuously updates the displayed information and detects important events such as process creation and termination. The system also records important events in a log file. This project helps in understanding how Linux provides operating system and process information to user-space applications and demonstrates important operating system concepts such as process management, resource management, and system monitoring.
